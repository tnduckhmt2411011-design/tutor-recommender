# Tài liệu đồ án

Thư mục chứa toàn bộ tài liệu nghiên cứu, thiết kế hệ thống và quy trình quản trị dự án.

## 1. Cấu trúc tài liệu

- `thesis/`: Bản thảo đề cương, nhận xét giáo viên hướng dẫn, hình ảnh/sơ đồ kiến trúc, báo cáo khóa luận và slides thuyết trình.
- `design/`: Đặc tả thiết kế kỹ thuật chi tiết: từ điển dữ liệu (`data-dictionary.md`), thông số thuật toán tính điểm (`scoring-spec.md`), và hợp đồng API (`api-contract.md`).
- `scrum/`: Tài liệu vận hành phương pháp Scrum của nhóm: vai trò, definition of done, thỏa thuận làm việc, backlog, roadmap và biên bản các sprint.
- `decisions/`: Nhật ký ghi nhận các quyết định kiến trúc và công nghệ quan trọng (Architecture Decision Records - ADR).
