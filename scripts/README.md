# Scripts - Các tiện ích hỗ trợ tự động hóa

Thư mục lưu trữ các kịch bản (scripts) chạy tự động phục vụ quá trình phát triển đồ án.

## 1. Mục đích dự kiến

- Scripts thu thập và cào dữ liệu công khai (crawler/scraper).
- Scripts sinh dữ liệu giả lập (synthetic data generation) phục vụ kiểm thử thuật toán.
- Scripts chuẩn hóa, làm sạch và nạp dữ liệu mẫu vào cơ sở dữ liệu SQLite.
- Scripts chạy đánh giá hàng loạt kịch bản kiểm thử (batch scenario evaluation).

## 2. Cách sử dụng

Các hướng dẫn thực thi script sẽ được cập nhật cụ thể trong từng giai đoạn phát triển (Sprint 1 trở đi).
